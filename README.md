# 📚 UxiLibris - Gestor de Lecturas Personal

Una aplicación móvil moderna diseñada para amantes de la lectura que desean llevar un registro detallado de su colección, lecturas en curso y deseos futuros.

## 🚀 Características Actuales
- **Gestión de Temas:** Soporte para modo claro y oscuro mediante `Provider`.
- **Filtros Avanzados:** Organización de libros por estado de lectura y búsqueda por título o autor.
- **UI Moderna:** Uso de Material 3, fuentes personalizadas (Montserrat Alternates) y fondos dinámicos.
- **Persistencia Temporal:** Carga inicial de datos mediante un archivo JSON local.

## 🏗️ Tecnologías utilizadas
- **Frontend:** Flutter & Dart.
- **Gestión de Estado:** Provider.
- **Iconos:** Material Design Icons.
- **Fuentes:** Google Fonts.
